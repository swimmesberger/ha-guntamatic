# Guntamatic (read/write)

Read **all** DAQ channels from a Guntamatic heater and **control** it (boiler release,
control program, per-circuit heating program, hot-water reload) over the local
HTTP/CGI web interface with **API-key** authentication.

A read/write superset of the official `guntamatic` integration. See the README for
setup, options, entities, and safety notes.
